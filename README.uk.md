# AI Code Explainer

Кросбраузерне розширення для построкового аналізу та пояснення вихідного коду за допомогою нейромереж **Google Gemini Flash**. Дозволяє миттєво розбирати фрагменти коду на вебсторінках через контекстне меню або знімок виділеної області екрана.

---

## Можливості

* **Аналіз виділеного тексту:** виділіть будь-який фрагмент коду на сторінці → натисніть ПКМ → оберіть **«Аналізувати код»**.
* **Захоплення області екрана (Скриншот):** натисніть комбінацію гарячих клавіш (`Ctrl+Shift+X` за замовчуванням) і виділіть область із кодом.
* **Інтерактивне вікно відповіді:**
  * Вільне переміщення вікна мишкою за верхній заголовок (Drag-and-Drop).
  * Зміна розмірів з усіх 4 сторін та 4 кутів (розтягування по горизонталі та вертикалі).
  * Контрастне підсвічування синтаксису та інлайн-елементів коду.
* **Мультимовність:** автоматична генерація відповіді українською, англійською або російською мовою залежно від вибору в меню розширення.
* **Кросбраузерність:** єдина кодова база Manifest V3, яка працює в **Google Chrome** (Chromium) та **Mozilla Firefox**.
* **Миттєве скасування:** клавіша `Escape` або кнопка закриття `✕` переривають виконання мережевого запиту до API.

---

## Стек технологій

* **JavaScript (ES6+)**
* **WebExtensions API / Chrome Extensions API (Manifest V3)**
* **Google Gemini API** (`gemini-3.5-flash-lite`, `gemini-3.1-flash-lite`, `gemini-3.5-flash`, `gemini-3.8-flash`, `gemini-3.6-flash`)
* **OffscreenCanvas API** (для обрізання зображень у фоновому скрипті)

## Встановлення та налаштування

### 1. Клонування репозиторію
```bash
git clone [https://github.com/ВАШ_НІК/ВАШ_РЕПОЗИТОРІЙ.git](https://github.com/ВАШ_НІК/ВАШ_РЕПОЗИТОРІЙ.git)
cd AI_Code_Explainer

2. Додавання API-ключа

    Отримайте безкоштовний ключ API в Google AI Studio.

    Створіть у корені проєкту файл config.js:

    const API_KEY = "ВАШ_ДІЙСНИЙ_КЛЮЧ_GEMINI";

3. Запуск у браузері

Google Chrome / Chromium (Brave, Edge, Opera)

    Відкрийте сторінку chrome://extensions/.

    Увімкніть перемикач «Режим розробника» (Developer mode) у правому верхньому куті.

    Натисніть кнопку «Завантажити розпаковане розширення» (Load unpacked).

    Оберіть папку з файлами розширення.

Mozilla Firefox

    Відкрийте сторінку about:debugging#/runtime/this-firefox.

    Натисніть кнопку «Завантажити тимчасове доповнення...» (Load Temporary Add-on...).

    Оберіть файл manifest.json у корені проєкту.

Додавання нових моделей Gemini

Архітектура розширення передає ідентифікатор моделі напряму в URL запиту Google AI API (/models/${modelName}:generateContent), тому для підключення нової моделі не потрібно змінювати мережеву логіку:

    Відкрийте файл popup.html.

    Знайдіть блок списку <select id="modelSelect">.

    Додайте новий тег <option> із точним системним ідентифікатором моделі з Google AI Studio:
    HTML

    <option value="ідентифікатор-моделі">Відображувана назва (наприклад, Gemini 3.5 Flash)</option>

    (Опціонально) Якщо ви бажаєте зробити нову модель вибором за замовчуванням при першому запуску, відкрийте background.js і вкажіть її ідентифікатор:

    const modelName = result.selectedModel || 'ідентифікатор-нової-моделі';

    Перезавантажте розширення на сторінці chrome://extensions/ або about:debugging.
