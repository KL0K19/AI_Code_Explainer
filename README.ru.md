# AI Code Explainer

Кроссбраузерное расширение для построчного анализа и объяснения исходного кода с помощью нейросетей **Google Gemini Flash**. Позволяет мгновенно разбирать фрагменты кода на веб-страницах через контекстное меню или снимок выделенной области экрана.

---

## Возможности

* **Анализ выделенного текста:** выделите любой фрагмент кода на странице → нажмите ПКМ → выберите **«Анализировать код»**.
* **Захват области экрана (Скриншот):** нажмите комбинацию горячих клавиш (`Ctrl+Shift+X` по умолчанию) и выделите область с кодом.
* **Интерактивное окно ответа:**
  * Свободное перемещение окна мышкой за верхний заголовок (Drag-and-Drop).
  * Изменение размеров со всех 4 сторон и 4 углов (растягивание по горизонтали и вертикали).
  * Контрастная подсветка синтаксиса и строчных элементов кода.
* **Мультиязычность:** автоматическая генерация ответа на русском, украинском или английском языке в зависимости от настроек в меню расширения.
* **Кроссбраузерность:** единая кодовая база Manifest V3, работающая в **Google Chrome** (Chromium) и **Mozilla Firefox**.
* **Мгновенная отмена:** клавиша `Escape` или кнопка закрытия `✕` прерывают выполнение сетевого запроса к API.

---

## Стек технологий

* **JavaScript (ES6+)**
* **WebExtensions API / Chrome Extensions API (Manifest V3)**
* **Google Gemini API** (`gemini-3.5-flash-lite`, `gemini-3.1-flash-lite`, `gemini-3.5-flash`, `gemini-3.8-flash`, `gemini-3.6-flash`)
* **OffscreenCanvas API** (для обрезки изображений в фоновом скрипте)

## Установка и настройка

### 1. Клонирование репозитория
```bash
git clone [https://github.com/ВАШ_НИК/ВАШ_РЕПОЗИТОРИЙ.git](https://github.com/ВАШ_НИК/ВАШ_РЕПОЗИТОРИЙ.git)
cd AI_Code_Explainer

2. Добавление API-ключа

    Получите бесплатный ключ API в Google AI Studio.

    Создайте в корне проекта файл config.js:

    const API_KEY = "ВАШ_ДЕЙСТВУЮЩИЙ_КЛЮЧ_GEMINI";

3. Запуск в браузере

Google Chrome / Chromium (Brave, Edge, Opera)

    Откройте страницу chrome://extensions/.

    Включите тумблер «Режим разработчика» (Developer mode) в правом верхнем углу.

    Нажмите кнопку «Загрузить распакованное расширение» (Load unpacked).

    Выберите папку с файлами расширения.

Mozilla Firefox

    Откройте страницу about:debugging#/runtime/this-firefox.

    Нажмите кнопку «Загрузить временное дополнение...» (Load Temporary Add-on...).

    Выберите файл manifest.json в корне проекта.

Добавление новых моделей Gemini

Архитектура расширения передает идентификатор модели напрямую в URL запроса Google AI API (/models/${modelName}:generateContent), поэтому для подключения новой модели не требуется менять сетевую логику:

    Откройте файл popup.html.

    Найдите блок выпадающего списка <select id="modelSelect">.

    Добавьте новый тег <option> с точным системным идентификатором модели из Google AI Studio:
    HTML

    <option value="имя-модели">Отображаемое название (например, Gemini 3.5 Flash)</option>

    (Опционально) Если вы хотите сделать новую модель значением по умолчанию при первой установке, откройте background.js и укажите ее идентификатор в блоках фолбэка:

    const modelName = result.selectedModel || 'имя-новой-модели';

    Перезагрузите расширение на странице chrome://extensions/ или about:debugging.
